在 Anaconda Prompt 中（先 cd 到本工具解压目录，路径随你放置位置变化）：

cd /d "D:\你的路径\Planning-Tool-0.2.4-windows-portable"
call windows\_tool_env.bat
call windows\_conda_activate_planning_tool.bat
call windows\_set_outlook_tz.bat
python -m planning_tool.cli --tasks "任务表.xlsx" --calendar outlook --report schedule.md --ics schedule.ics

也可直接双击 Run-Outlook-Cli.bat 并把 xlsx 拖到窗口上。
