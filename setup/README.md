# setup — 安装与维护

| 脚本 | 说明 |
|------|------|
| `Install-Offline.bat` | 与根目录 `Install-Miniforge.bat` 相同（离线安装） |
| `Repair-Install.bat` | 当前目录重装依赖 |
| `Verify-Install.bat` | 检查 Miniforge / planning-tool / cli |
| `Save-Miniforge-Path.bat` | 写入 `.miniforge-base`（便于双击根目录 bat） |
| `legacy/` | 旧文件名兼容入口 |
